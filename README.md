
# VORTEX ROYALE

Battle Royale 3D para Android e PC.

## Características
- 60 jogadores por partida
- 3 mapas diferentes
- Trem voador
- Personagens com estilo anime
- Armas e munições
- Kits médicos
- Skins de personagens e armas
- Multiplayer online
- Sistema de inventário
- Marketplace de skins

## Desenvolvimento
Projeto desenvolvido com Godot Engine.
